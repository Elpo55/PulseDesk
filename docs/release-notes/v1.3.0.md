Sysora 1.3 speaks French, finds the games you installed with Steam, Epic Games, Riot or GOG, and lets you add any
other game in two clicks. Under the hood, the shared code now builds and is tested on Windows, Linux and macOS, the
first step towards a version for those systems. As before, everything stays on your PC: no account, no telemetry, no
network connection.

## Highlights

- **Sysora in French**: the whole interface, the analyses, diagnoses, alerts, reports and notifications are translated.
  Choose the language in Settings › General › Language (Windows language, English or Français); Sysora offers to
  restart to apply it. Dates and numbers follow your Windows regional format.
- **Games installed with a launcher**: Sysora reads the files Steam, the Epic Games Launcher, the Riot Client and GOG
  Galaxy keep on your PC to know which games are installed, and follows them automatically. It works offline, never
  scans whole drives, never starts a game and never changes the launchers' files. Games whose folder no longer exists
  are left out.
- **Confirm or ignore**: Settings › Games lists the games found. Confirm a game to keep following it even if the
  launcher is uninstalled, or ignore one you do not want followed.
- **Add a game**: "Add a game..." opens the Windows file picker to choose a game's program, even when it is not
  running. Sysora checks the file (a program, that exists, outside the Windows folder), refuses duplicates, and lets you
  point a game that moved to its new location without losing its place.

## Improvements

- Launcher helpers (Riot Client, League Client) are never mistaken for games.
- Settings › Games shows each game's name and folder, and warns when a game you added can no longer be found.
- New `--language=en` or `--language=fr` option to use a language for one run without changing the setting.

## For contributors

- The Windows-specific code moved to its own project (`Sysora.Infrastructure.Windows`); the rest of the infrastructure
  now targets plain .NET.
- First Linux and macOS data sources (CPU, memory, uptime, and disk space on Linux), tested on GitHub's Ubuntu and
  macOS runners. **There is no Linux or macOS application yet**: see [docs/platforms.md](https://github.com/Elpo55/Sysora/blob/main/docs/platforms.md) for what
  works where and how it was checked.
- CI runs on Windows, Ubuntu and macOS, and reports test totals and failures as annotations.
- New CONTRIBUTING, CODE_OF_CONDUCT and SECURITY files, issue forms and a pull request template.
- A guide for translators in [docs/development.md](https://github.com/Elpo55/Sysora/blob/main/docs/development.md#translating-sysora).

## Known limitations

- Texts already saved in your history (events, alerts, detected changes) stay in the language they were recorded in.
- Epic Games and GOG Galaxy detection follow the launchers' documented file formats but have not been tried yet with
  an installed game.

## Update from 1.2

Download and run the new installer: it updates Sysora in place. Your settings, local history, alerts, detected changes
and game sessions are kept. Close Sysora first, or let the installer close it. Sysora starts in your Windows language
when it is French or English; you can change it in Settings.

## Install

1. Download **`Sysora-1.3.0-setup-x64.exe`** (or `-arm64` for Windows on ARM) below.
2. Run it. By default Sysora is installed for all users in `Program Files` (administrator rights needed); the first
   screen also offers **Install for me only**, which needs no administrator rights.
3. Start Sysora from the Start menu.

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click
**More info**, then **Run anyway**. You can check the download against `SHA256SUMS.txt`.

**Requirements**: Windows 10 version 1809 or later, or Windows 11 (x64 or ARM64). Nothing else to install: the .NET
and Windows App SDK runtimes are included.
