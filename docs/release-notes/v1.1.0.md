PulseDesk 1.1 adds a recap of your game sessions, compares your PC's activity with its usual level over time, and
handles sleep and resume better. As before, everything stays on your PC: no account, no telemetry, no network
connection.

## Highlights

- **Gaming recap**: PulseDesk recognizes a game when it starts (Windows' own list of your games, or a game library
  folder such as Steam, Epic, Xbox or GOG; you can also mark or unmark an application) and shows a recap when it
  closes: averages and peaks of CPU, GPU, video memory, memory, disk and network, what the game itself used, the
  limits reached (memory nearly full, processor saturated...), the likely limiting factor, the busiest background
  applications and a comparison with your previous sessions of the same game. A notification opens the recap.
- **FPS is never estimated**: Windows offers no reliable frame-rate source to other applications, so the recap shows
  "Not available" rather than a made-up number.
- **Lighter while you play**: when a game is in front, PulseDesk pauses its own window updates and samples less often.
  The recap shows how much CPU PulseDesk itself used during the session.
- **Your usual activity**: Diagnosis compares the current activity with the last hour, today, yesterday, the last 7
  and 30 days, and the usual level at this hour, as soon as enough history exists (otherwise it says how much is
  missing).
- **Sleep and resume**: the history in progress is saved before the PC sleeps, and every value is refreshed as soon as
  it wakes up.

## Fixes

- The CPU no longer appears as "Not available" for a second every two hours or so (a Windows counter starting over).
- A low disk space alert is no longer raised again, with a new notification, every time PulseDesk starts: the same
  alert continues while the disk stays full.
- A history database damaged while PulseDesk runs is set aside and recreated instead of failing until the next start.

## Update from 1.0

Download and run the new installer: it replaces PulseDesk 1.0 in place. Your settings, local history and alerts are
kept. Close PulseDesk first, or let the installer close it.

## Install

1. Download **`PulseDesk-1.1.0-setup-x64.exe`** (or `-arm64` for Windows on ARM) below.
2. Run it. By default PulseDesk is installed for all users in `Program Files` (administrator rights needed); the first
   screen also offers **Install for me only**, which needs no administrator rights.
3. Start PulseDesk from the Start menu.

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click
**More info**, then **Run anyway**. You can check the download against `SHA256SUMS.txt`.

**Requirements**: Windows 10 version 1809 or later, or Windows 11 (x64 or ARM64). Nothing else to install: the .NET
and Windows App SDK runtimes are included.

## Notes

- PulseDesk only shows values Windows actually provides; anything else appears as "Not available" (for example FPS,
  temperatures, or network usage per application).
- A game Windows does not recognize and that is not installed in a game library folder is followed once you mark it
  as a game in Settings › Gaming.
