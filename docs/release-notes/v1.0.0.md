PulseDesk 1.0 doesn't stop at showing numbers: it detects what is wrong, explains it, and helps you understand what
happens on your PC. Everything stays on your PC: no account, no telemetry, no network connection.

## Highlights

- **Diagnosis**: "Why is my PC slow?" PulseDesk checks the processor, memory, disks, GPU, network, applications and
  uptime, and explains each finding with the data behind it and a confidence level.
- **Replay**: look back at the last minutes (every second) or the last hours (per minute), move a cursor through time,
  and read a summary of what happened.
- **App Impact**: see which applications weigh the most on your PC, this session or over days, with an explained
  impact score and each application's history.
- **Changes**: see what changed recently (applications installed, removed or updated, startup programs, Windows build,
  devices, disk space, average usage).
- **Smart alerts**: alerts only for problems that last or are unusual for your PC, never for short spikes. Optional
  Windows notifications.
- **New dashboard**: overall status (Healthy, Attention, Problem detected), mini-graphs, insights and quick actions.
- Local history with automatic retention, configurable and deletable from Settings.

All the earlier features are still there: real-time CPU, memory, GPU, storage and network monitoring, the process
list, system information, tray mode, start with Windows, light and dark themes.

## Install

1. Download **`PulseDesk-1.0.0-setup-x64.exe`** (or `-arm64` for Windows on ARM) below.
2. Run it. By default PulseDesk is installed for all users in `Program Files` (administrator rights needed); the first
   screen also offers **Install for me only**, which needs no administrator rights.
3. Start PulseDesk from the Start menu.

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click
**More info**, then **Run anyway**. You can check the download against `SHA256SUMS.txt`.

**Requirements**: Windows 10 version 1809 or later, or Windows 11 (x64 or ARM64). Nothing else to install: the .NET
and Windows App SDK runtimes are included.

**Uninstall**: Settings › Apps › Installed apps › PulseDesk › Uninstall. Your settings and local history are kept
unless you choose to delete them.

## Notes

- PulseDesk only shows values Windows actually provides; anything else appears as "Not available" (for example
  CPU temperature, or network usage per application).
- PulseDesk needs about 4 hours of history before it compares activity with your usual behavior.
- Details of the new modules and their limits: [IMPLEMENTATION_NOTES.md](https://github.com/Elpo55/PulseDesk/blob/v1.0.0/IMPLEMENTATION_NOTES.md).
