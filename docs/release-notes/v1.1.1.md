PulseDesk is now **Sysora** — *Your PC, Explained.* This release changes the name only: features, look and behavior
are those of 1.1. As before, everything stays on your PC: no account, no telemetry, no network connection.

## What changes

- The application, its window, notification area icon, notifications, Start menu shortcut and installer are now named
  Sysora (`Sysora.exe`).
- The project moved to [github.com/Elpo55/Sysora](https://github.com/Elpo55/Sysora). Links to the former address keep
  working.

## Update from PulseDesk

Download and run the new installer: it is recognized as an update and replaces PulseDesk. Close PulseDesk first, or
let the installer close it. Nothing is lost:

- Your settings, local history, alerts, detected changes and game sessions are moved from `%LOCALAPPDATA%\PulseDesk`
  to `%LOCALAPPDATA%\Sysora` the first time Sysora starts.
- If PulseDesk started with Windows, Sysora does, with the same choice (including "turned off" in Windows Settings ›
  Apps › Startup).
- A PulseDesk installation in a folder named `PulseDesk` is replaced by a `Sysora` folder next to it, and the old Start
  menu and desktop shortcuts are removed.

## Install

1. Download **`Sysora-1.1.1-setup-x64.exe`** (or `-arm64` for Windows on ARM) below.
2. Run it. By default Sysora is installed for all users in `Program Files` (administrator rights needed); the first
   screen also offers **Install for me only**, which needs no administrator rights.
3. Start Sysora from the Start menu.

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click
**More info**, then **Run anyway**. You can check the download against `SHA256SUMS.txt`.

**Requirements**: Windows 10 version 1809 or later, or Windows 11 (x64 or ARM64). Nothing else to install: the .NET
and Windows App SDK runtimes are included.
